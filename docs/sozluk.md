# 📘 Numex Sözlüğü

| Terim | Anlam |
|---|---|
| **Core — Beyin** | Tüm Numex ürünlerinin arkasındaki otonom ajan motoru (`@numex-ai/core`) |
| **Pipeline (Boru Sistemi)** | Her isteğin geçtiği 5 aşamalı işleme hattı: Boru 1, AI Motor, Boru 2A, Boru 2B, yanıt |
| **Boru 1** | Prompt güçlendirme, bağlam ekleme |
| **Boru 2A** | Türkçe düzeltme, format ve ton |
| **Boru 2B** | Kalite kontrol ve doğrulama |
| **Detective Mode™ (Dedektif Modu)** | Aynı soruyu birden çok modele çözdürüp hakemin en iyi cevabı gerekçesiyle seçmesi |
| **Hakem Sistemi** | Detective Mode ve Multi-Agent'ta çıktıları değerlendiren katman |
| **Multi-Agent** | Görevi alt görevlere bölüp uzman ajanlara dağıtan orkestratör mimarisi |
| **DeepView™** | Çoklu uzman orkestratörü ve AI düşüncesinin 6 katmanlı görselleştirmesi |
| **Master Plan** | DeepView'in ürettiği tek entegre belge |
| **Swarm Council** | Mimar, Kodlayıcı, Denetçi, Tasarımcı'dan oluşan 4'lü ajan konseyi |
| **FinishGate** | "Bitti" demeden önce canlı kanıt (HTTP 200, test, DOM) isteyen kapı |
| **Self-Healing Loop** | 3 turluk otonom hata bulma ve düzeltme döngüsü |
| **Omni-Vision** | Headless Chrome ile DOM ve 3D Canvas'ı görsel denetleme |
| **Self-Evolving Memory** | Çözümleri `.agents/skills/` altında öğrenen hafıza |
| **`.numex/`** | Projedeki ajan hafızası: RAG indeksi, denetim izi, checkpoint'ler, misyon durumu |
| **NCP** | Blender, Unity, Figma gibi araçlar için Numex eklenti protokolü |
| **Numex Çözüm** | Codex IDE içindeki asistanın adı |
| **Hata Avcısı** | Codex'te hata kök nedenini bulan mod |
| **Misyon (`numex mission`)** | İzole çalışma alanlarında uzun süreli otonom görev |
| **Uzaktan CLI** | Tarayıcıdan/telefondan kendi PC'nize komut gönderme köprüsü |
| **Profil** | Numex Pro, Fast, Vision, Code — işe göre model yönlendirmesi |
| **Karakter** | `@FatmaAna`, `@MuhasebeciYunus` gibi kültüre özgü uzman kişilikler |
| **Numex Kredisi** | Abonelik dışı, 12 ay geçerli kullandıkça öde paketleri |
| **Zaman bileti (Time-Pass)** | 8 saat–7 gün süreli, otomatik yenilenmeyen PRO erişimi |
| **`nx_live_`** | Numex API anahtarı öneki |
| **Forge** | Gitea tabanlı Numex Git sunucusu |
| **Hub** | Forge üzerinde AI destekli depo yönetimi ve topluluk vitrini |
| **Çatalla** | Fork — bir depoyu kendi hesabına kopyalayıp geliştirmek |
| **Selçuklu yıldızı** | 180° çevrilen Numex logosunda ortaya çıkan 8 köşeli yıldız |
